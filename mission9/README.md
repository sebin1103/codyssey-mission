## 1. 스토리 배경

오랜 시간이 걸려 `emergency_storage_key.zip`의 암호를 풀었지만, ZIP 파일 안에 있는 텍스트를 입력해도 문은 열리지 않았다. 암호는 맞았으나 텍스트가 너무 단순했다.

한송희 박사는 고흥에서 기지 구조를 설계하던 엔지니어를 떠올렸다. 그 사람의 책상에는 로마 병정 피규어가 유난히 많았다.

> **"아, 카이사르 암호!"**

화성까지 와서 뭘 훔쳐갈 사람도 없으니, 최소한의 보안 장치로 로마 시대의 단순한 암호 기법을 사용했을 것이다.  
로마 시대의 암호를 화성에서 풀게 될 줄은 몰랐지만, 이렇게 단순한 암호를 써줘서 오히려 고마울 따름이었다.

## 2. 카이사르 암호란?

**카이사르 암호(Caesar Cipher)**는 기원전 로마 황제 율리우스 카이사르가 군사 통신에 사용한 암호 기법입니다.  
알파벳을 일정한 수(자리수, shift)만큼 밀어서 암호화하고, 반대로 당겨서 복호화합니다.

### 암호화 예시 (shift = 3)

```
평문:  A  B  C  D  E  F  ...  X  Y  Z
암호:  D  E  F  G  H  I  ...  A  B  C
```

- `A` → 3칸 앞으로 이동 → `D`
- `Z` → 3칸 앞으로 이동 → `C` (알파벳 끝에서 처음으로 순환)

### 복호화 원리

암호문에서 같은 자리수만큼 **반대 방향**으로 이동하면 원래 평문을 얻을 수 있습니다.

```
암호:  D  E  F  G  H  I  ...  A  B  C
평문:  A  B  C  D  E  F  ...  X  Y  Z
```

자리수를 모를 때는 **0~25까지 26가지를 모두 시도(brute force)**하여 의미 있는 문장을 찾습니다.

### 사전 조건

- Python 3.x 설치 필요
- `main.py`와 `password.txt`가 **같은 폴더**에 있어야 합니다

```bash
python3 main.py
```

### 실행 후 흐름

2. 자리수 0~25를 순서대로 시도하며 해독 결과를 매 자리수마다 출력합니다.

4. 자동 탐지 실패 시, 화면 결과를 눈으로 확인한 뒤 자리수를 직접 입력합니다.

## 6. 함수 상세 설명

### `read_password_file(file_path)`

**역할**: `password.txt`를 열어 암호문 문자열을 반환합니다.

**파라미터**

| 파라미터 | 타입 | 설명 |
|---|---|---|
| `file_path` | `str` | 읽을 파일의 경로 |

**반환값**: `str` (성공) 또는 `None` (실패)

**예외처리**

| 예외 | 처리 내용 |
|---|---|
| `FileNotFoundError` | 파일 경로를 포함한 오류 메시지 출력 후 `None` 반환 |
| `PermissionError` | 읽기 권한 없음 메시지 출력 후 `None` 반환 |
| `Exception` | 예기치 않은 모든 오류를 포착해 `None` 반환 |

```python
def read_password_file(file_path):
    try:
        with open(file_path, 'r', encoding='utf-8') as file:
            return file.read().strip()
    except FileNotFoundError:
        print(f'오류: 파일을 찾을 수 없습니다 → {file_path}')
        return None
    except PermissionError:
        print(f'오류: 파일 읽기 권한이 없습니다 → {file_path}')
        return None
    except Exception as e:
        print(f'오류: 파일을 읽는 중 예기치 않은 오류가 발생했습니다 → {e}')
        return None
```

### `decode_with_shift(target_text, shift)`

**역할**: 카이사르 암호의 핵심 해독 로직입니다. 주어진 자리수만큼 알파벳을 역방향으로 이동합니다.

**파라미터**

| 파라미터 | 타입 | 설명 |
|---|---|---|
| `target_text` | `str` | 해독할 암호 문자열 |
| `shift` | `int` | 0~25 사이의 카이사르 암호 자리수 |

**반환값**: `str` — 해독된 문자열

**처리 규칙**

| 문자 유형 | 처리 방법 |
|---|---|
| 소문자 `a`~`z` | 자리수만큼 역방향 이동, 알파벳 범위 내에서 순환 |
| 대문자 `A`~`Z` | 자리수만큼 역방향 이동, 알파벳 범위 내에서 순환 |
| 공백, 숫자, 특수문자 | 변환 없이 원본 그대로 유지 |

```python
def decode_with_shift(target_text, shift):
    decoded_chars = []
    for char in target_text:
        if 'a' <= char <= 'z':
            decoded_chars.append(
                chr(((ord(char) - ord('a') - shift) % 26) + ord('a'))
            )
        elif 'A' <= char <= 'Z':
            decoded_chars.append(
                chr(((ord(char) - ord('A') - shift) % 26) + ord('A'))
            )
        else:
            decoded_chars.append(char)
    return ''.join(decoded_chars)
```

## 7. 핵심 알고리즘 해설

### 모듈러 연산으로 알파벳 순환 처리

카이사르 암호에서 가장 중요한 부분은 알파벳의 끝(`Z`)에서 다시 처음(`A`)으로 순환하는 처리입니다.  
이를 **모듈러 연산(`% 26`)**으로 해결합니다.

```
decoded_index = (암호 문자의 위치 - 자리수) % 26
```

### 예시: 암호문 `"B ehox Ftkl"`, 자리수 19

| 암호 문자 | 알파벳 위치 | -19 계산 | % 26 결과 | 해독 문자 |
|---|---|---|---|---|
| `B` | 1 (대문자) | 1 - 19 = -18 | (-18 + 26) % 26 = **8** | `I` |
| `e` | 4 (소문자) | 4 - 19 = -15 | (-15 + 26) % 26 = **11** | `l` |
| `h` | 7 (소문자) | 7 - 19 = -12 | (-12 + 26) % 26 = **14** | `o` |
| `o` | 14 (소문자) | 14 - 19 = -5 | (-5 + 26) % 26 = **21** | `v` |
| `x` | 23 (소문자) | 23 - 19 = 4 | 4 % 26 = **4** | `e` |
| `F` | 5 (대문자) | 5 - 19 = -14 | (-14 + 26) % 26 = **12** | `M` |
| `t` | 19 (소문자) | 19 - 19 = 0 | 0 % 26 = **0** | `a` |
| `k` | 10 (소문자) | 10 - 19 = -9 | (-9 + 26) % 26 = **17** | `r` |
| `l` | 11 (소문자) | 11 - 19 = -8 | (-8 + 26) % 26 = **18** | `s` |

**결과: `"I love Mars"`**

## 9. 보너스 과제 — 텍스트 사전 자동 탐지

### 개요

26가지 자리수를 눈으로 하나하나 확인하는 대신, **텍스트 사전(dictionary)**을 활용해 의미 있는 단어를 자동으로 탐지하고 반복을 조기에 중단합니다.

### 사전 구성

```python
dictionary = [
    'mars', 'love', 'base', 'roman', 'caesar',
    'system', 'secret', 'open', 'door', 'the'
]
```

화성 기지 문맥에서 나타날 가능성이 높은 단어들로 구성했습니다.

### 동작 방식

```python
lower_decoded = decoded_text.lower()   # 대소문자 구분 없이 비교
for word in dictionary:
    if word in lower_decoded:          # 해독 결과에 사전 단어 포함 여부 확인
        print(f'[자동 탐지] 키워드 "{word}" 발견 → 자리수 {shift}번에서 탐색 중단')
        return shift, decoded_text     # 즉시 반복 중단 후 반환
```

1. 해독된 문자열을 소문자로 변환해 대소문자 구분 없이 비교합니다.
2. 사전의 각 단어가 해독 결과에 포함되어 있는지 확인합니다.
3. 하나라도 발견되면 즉시 반복을 중단하고 해당 자리수와 해독 결과를 반환합니다.

### 활용 효과

- 사전 단어가 일치하는 경우: **자동으로 탐색 종료 → result.txt 자동 저장**
- 사전 단어가 없는 경우: 26자리 모두 출력 후 사용자가 직접 자리수 입력

## 10. 예외처리 설계

파일을 다루는 모든 함수에 예외처리를 적용해, 예상치 못한 오류가 발생해도 프로그램이 안전하게 동작합니다.

### 파일 읽기 (`read_password_file`)

```
FileNotFoundError  → 파일 경로 오류 메시지 출력 후 None 반환 (프로그램 안전 종료)
PermissionError    → 읽기 권한 오류 메시지 출력 후 None 반환
Exception          → 예기치 않은 모든 오류 포착 후 None 반환
```

### 파일 쓰기 (`save_result_file`)

```
PermissionError    → 쓰기 권한 오류 메시지 출력
Exception          → 예기치 않은 모든 오류 포착 및 메시지 출력
```

### 사용자 입력 (`main`)

```
ValueError         → 숫자가 아닌 입력 시 오류 메시지 출력 후 프로그램 종료
범위 초과 입력     → 0~25 범위를 벗어나는 숫자 입력 시 오류 메시지 출력 후 종료
```

| **경고 메시지** | 경고 없이 모든 코드 실행 가능 |

## 12. PEP 8 준수 사항

이 프로젝트는 [PEP 8 — 파이썬 코드 스타일 가이드](https://peps.python.org/pep-0008/)를 준수합니다.

### 주요 적용 항목

- **들여쓰기**: 탭 대신 스페이스 4칸 사용
- **줄 길이**: 한 줄은 79자 이내로 제한 (긴 표현식은 괄호로 묶어 줄 바꿈)
- **공백**: 연산자 앞뒤, 쉼표 뒤에 공백 추가 (`shift = 0`, `(a, b)`)
- **함수명**: `snake_case` 사용 (`caesar_cipher_decode`, `read_password_file`)
- **Docstring**: 모든 함수에 `"""` 형식의 독스트링 작성 (Args / Returns 포함)
- **문자열**: 기본적으로 `' '` (작은따옴표) 사용, 내부에 `'` 포함 시 `" "` 사용
- **불필요한 공백 금지**: 괄호 내부 공백, 후행 공백 없음
- **빈 줄**: 최상위 함수 사이에 빈 줄 2개, 메서드 사이에 빈 줄 1개
- **`if __name__ == '__main__'`**: 스크립트 직접 실행 시에만 `main()` 호출
