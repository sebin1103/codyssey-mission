# 🎙️ JAVIS — 화성 기지 음성 기록 시스템

> *"하루의 기록을 말로 남기면 어떨까?"*
> — 한송희 박사, 화성 기지에서

---

## 📖 배경 이야기

물자도 어느 정도 확보됐고, 계산기도 만들어서 앞으로 몇 달은 버틸 수 있다는 걸 확인했다.
화성에 고립된 지 얼마나 됐는지 모르겠지만, 한 가지 다행인 점은 — 화성의 하루는 지구와 거의 같은 **24시간 39분**이라는 것. 생체 리듬을 맞추느라 고생할 필요도 없었고, 오히려 덤으로 39분이 더 생기는 느낌이었다.

**한송희 박사**는 매일 화성에서의 생활을 기록하려 했지만, 집중하다 보면 자꾸 건너뛰게 되는 게 문제였다.

> *"글로 쓰는 게 번거롭다면, 말로 남기면 되지 않을까?"*

말을 알아듣고 기록해주는 무언가가 필요했다. 한송희 박사는 이미 알고 있었다 — 필요한 기능은 이미 라이브러리 형태로 존재한다는 것을. 그렇게 **JAVIS(화성 기지 음성 기록 시스템)** 프로젝트가 시작됐다.

---

## 🚀 주요 기능

- **시스템 마이크 자동 인식** — 연결된 입력 장치를 탐색하고 기본 마이크를 선택
- **음성 녹음** — Enter 키를 누를 때까지 실시간으로 음성을 녹음
- **자동 파일 저장** — 녹음 시작 시각 기준으로 `년월일-시간분초.wav` 형식으로 저장
- **날짜 범위 검색** *(보너스 과제)* — 특정 기간의 녹음 파일을 조회

## ⚙️ 설치 방법

Python 기본 라이브러리 외에 음성 녹음을 위한 **pyaudio** 패키지가 필요하다.

```bash
pip install pyaudio
```

> macOS에서 pyaudio 설치 시 오류가 발생하면 아래 명령어를 먼저 실행한다.
> ```bash
> brew install portaudio
> pip install pyaudio
> ```

### `get_microphone_info(audio)`

```python
def get_microphone_info(audio):
    """시스템에서 사용 가능한 마이크 목록을 출력하고 기본 입력 장치 인덱스를 반환한다."""
```

pyaudio를 통해 시스템에 연결된 모든 오디오 장치를 순회하며, `maxInputChannels > 0`인 장치를 마이크로 인식하여 목록을 출력한다.
기본 입력 장치를 가져와 인덱스를 반환하며, 마이크가 없으면 `None`을 반환한다.

---

### `generate_filename()`

```python
def generate_filename():
    """현재 날짜와 시간을 기반으로 파일 이름을 생성한다."""
```

`datetime.datetime.now()`로 현재 시각을 가져와 `YYYYMMDD-HHMMSS.wav` 형식의 파일명을 생성한다.

예) `20260507-143022.wav`

---

### `save_wav_file(file_path, audio, frames)`

```python
def save_wav_file(file_path, audio, frames):
    """녹음된 데이터를 WAV 파일로 저장한다."""
```

Python 표준 라이브러리인 `wave` 모듈을 사용하여 녹음 데이터를 WAV 파일로 저장한다.
채널 수, 샘플 크기, 샘플 레이트를 설정한 뒤 녹음된 프레임을 이어붙여 파일에 쓴다.

---

### `record_audio()`

```python
def record_audio():
    """시스템 마이크를 인식하고 음성을 녹음하여 records 폴더에 저장한다."""
```

전체 녹음 흐름을 담당하는 핵심 함수다.

1. `create_records_dir()` — 저장 폴더 준비
2. `get_microphone_info()` — 마이크 탐색 및 선택
3. **별도 스레드**(`threading.Thread`)로 Enter 키 입력을 감지하여 녹음 중단
4. `is_recording[0]`이 `True`인 동안 스트림에서 오디오 청크를 읽어 `frames` 리스트에 누적
5. Enter 키 입력 감지 시 스트림을 닫고 `save_wav_file()`로 파일 저장

> **`is_recording`을 리스트로 감싼 이유**
> Python에서 내부 함수(클로저)는 외부 변수를 직접 재할당할 수 없다.
> 리스트로 감싸면 내용물을 변경하는 것이므로 스레드 간 상태 공유가 가능하다.

### `list_recordings_by_date(start_date_str, end_date_str)` *(보너스 과제)*

```python
def list_recordings_by_date(start_date_str, end_date_str):
    """특정 날짜 범위에 해당하는 녹음 파일 목록을 출력한다."""
```

`records` 폴더의 WAV 파일들을 순회하며 파일명에서 날짜/시간 정보를 파싱한다.
입력받은 시작일(`YYYYMMDD`)과 종료일(`YYYYMMDD`) 범위에 포함되는 파일만 출력한다.
종료일은 해당 날의 `23:59:59`까지 포함하도록 처리된다.

**사용 예시:**
```
시작 날짜 입력 (YYYYMMDD): 20260501
종료 날짜 입력 (YYYYMMDD): 20260510

[날짜 검색] 20260501 ~ 20260510 범위의 녹음 파일:
  2026년 05월 07일  14:30:22  →  20260507-143022.wav
  2026년 05월 09일  09:15:00  →  20260509-091500.wav

  총 2개의 파일을 찾았습니다.
```

## 🛠️ 사용 기술 및 라이브러리

| 라이브러리 | 종류 | 용도 |
|---|---|---|
| `pyaudio` | 외부 | 마이크 인식 및 오디오 스트림 처리 |
| `wave` | 표준 | WAV 파일 저장 |
| `datetime` | 표준 | 녹음 시각 기반 파일명 생성 |
| `threading` | 표준 | Enter 키 감지와 녹음 병렬 처리 |
| `os` | 표준 | 폴더 생성 및 파일 목록 조회 |
| `sys` | 표준 | 오류 시 프로그램 종료 |
